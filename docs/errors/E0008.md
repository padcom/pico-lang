# E0008: unterminated regex literal

A `/…/` regex literal that reaches the end of the line without its closing `/`. Regex literals
can't span lines. A `/` inside a character class (`[/]`) or escaped as `\/` doesn't end the
literal, so an unbalanced `[` also leaves it open.

```ppl
const pattern = /[a-z]+
println(pattern.test("abc"))
```

Close the regex with `/` (followed by any flags), and escape a `/` that's part of the pattern.

```ppl
const pattern = /[a-z]+/
println(pattern.test("abc"))
```
