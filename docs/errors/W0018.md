# W0018: an operation's result doesn't depend on its operands

When the left side of `??` (or the target of `??=`) can't be `null`, the right side is never used. The rule is off by default; turn it on with `"lint": { "constantBinary": true }` in `project.json`.

```ts
function size(n: i32): i32 { n ?? 0 }
println(size(3))
```

Remove the fallback, or make the value nullable if it can be missing:

```ts
function size(n: i32?): i32 { n ?? 0 }
println(size(3))
```
