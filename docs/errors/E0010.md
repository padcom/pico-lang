# E0010: invalid regular expression literal

A regex literal that isn't a valid regular expression: unbalanced parentheses, a quantifier
with nothing to repeat, an unknown or repeated flag. ppl checks regex literals at compile time,
so a broken pattern fails the build instead of throwing when the program runs.

```ppl
const pattern = /(abc/
println(pattern.test("abc"))
```

Fix the pattern (here, close the group) or escape characters meant literally (`\(`).

```ppl
const pattern = /(abc)/
println(pattern.test("abc"))
```
