# W0007: a function has more parameters than the maximum

A function with many parameters is hard to call correctly and usually does several things. The default maximum is 4. The rule is off by default; turn it on with `"lint": { "maxParams": true }`, or give another maximum (`"maxParams": n`) in `project.json`.

```ts
function rect(x: i32, y: i32, w: i32, h: i32, color: string): string {
  `${color} ${x},${y} ${w}x${h}`
}
println(rect(0, 0, 10, 20, "red"))
```

Group parameters that belong together:

```ts
struct Box { x: i32; y: i32; w: i32; h: i32 }

function rect(b: Box, color: string): string {
  `${color} ${b.x},${b.y} ${b.w}x${b.h}`
}
println(rect(Box { x: 0, y: 0, w: 10, h: 20 }, "red"))
```
