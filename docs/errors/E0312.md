# E0312: field given twice in a struct literal

A struct literal sets the same field more than once. Only one of the values could be used, so
pico reports the duplicate instead of silently keeping the last one.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, x: 2, y: 3 }
```

Remove the extra field.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 2, y: 3 }
```
