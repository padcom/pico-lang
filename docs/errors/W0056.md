# W0056: a line breaks after an operator instead of before it

When an expression continues on the next line, the operator starts that line, where the reader sees it. `+` and `-` are the exception: a line starting with them begins a new statement in pico (spec §1.2), so they stay at the end of the line. The rule is off by default; turn it on with `"lint": { "operatorLinebreak": true }` in `project.json`.

```ts
const width = 4
const height = 5
const area = width *
  height
println(area)
```

Break the line before the operator:

```ts
const width = 4
const height = 5
const area = width
  * height
println(area)
```
