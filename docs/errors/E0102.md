# E0102: invalid assignment target

The left side of `=` (or `+=`, `++`, …) isn't a place that can hold a value. Only variables,
fields (`a.b`), index expressions (`a[i]`) and destructuring patterns can be assigned to; a
literal or a call result can't.

```ppl
let x = 1
5 = x
```

Put the variable on the left and the value on the right.

```ppl
let x = 1
x = 5
println(x)
```
