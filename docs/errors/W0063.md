# W0063: a used name starts or ends with `_`

A leading or trailing `_` marks a variable, parameter or function as unused (the `unused` rule skips it), so one that is used is misnamed. Unused ones are fine: that's how to keep state or a parameter you don't need (decision 332). The rule is off by default; turn it on with `"lint": { "underscoreDangle": true }` in `project.json`.

```ts
const _limit = 3
println(_limit)
```

Drop the `_` from names that are used:

```ts
const limit = 3
const _reserved = 0
println(limit)
```
