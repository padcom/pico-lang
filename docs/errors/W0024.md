# W0024: a `catch` only rethrows what it caught

A `catch` (the last one) that only rethrows what it caught does nothing: the error would pass through without it. The rule is off by default; turn it on with `"lint": { "uselessCatch": true }` in `project.json`.

```ts
function parse(s: string): i32 throws Error {
  try {
    if (s == "") throw new Error("empty")
    1
  } catch (e) {
    throw e
  }
}
println(parse("1"))
```

Remove it, or handle the error:

```ts
function parse(s: string): i32 throws Error {
  if (s == "") throw new Error("empty")
  1
}
println(parse("1"))
```
