# E0358: a generic method dispatched at run time

A generic method is instantiated per type argument at compile time, one copy for each type it's
called with. A virtual call goes through a single vtable (or interface) slot chosen at run time,
and one slot can't hold every copy, so a generic method can't be `virtual`, `abstract`, an
`override`, or a method of an interface.

```ts
class Help {
  public virtual groupItems<T>(items: T[]): T[] { return items }
}
```

Make it a plain (final) method, or move the type parameter to the class, so that each instance
of the class has its own vtable:

```ts
class Help {
  public groupItems<T>(items: T[]): T[] { return items }
}
```
