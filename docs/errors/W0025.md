# W0025: a plain string contains a `${…}` substitution

A plain string doesn't substitute `${…}`; only a template (`` `…` ``) does. The rule is off by default; turn it on with `"lint": { "templateInString": true }` in `project.json`.

```ts
const name = "Ann"
println("Hello, ${name}")
```

Use a template:

```ts
const name = "Ann"
println(`Hello, ${name}`)
```
