# E0315: array literal without a known element type

An empty array literal `[]` with nothing that says what it holds. ppl arrays have one
element type, and with no elements and no expected type there is nothing to infer it from.

```ppl
const xs = []
```

Annotate the variable (or pass the literal where an array type is expected).

```ppl
const xs: i32[] = []
```
