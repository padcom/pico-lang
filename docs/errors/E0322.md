# E0322: override of a method that can't be overridden

A method is marked `override` but the base class has no matching method that allows it.
Methods are final unless declared `virtual` (or `abstract`), so the base class controls which
methods subclasses can replace.

```ppl
class Base {
  public run(): string { "base" }
}
class Child extends Base {
  public override run(): string { "child" }
}
```

Make the base method `virtual`, or drop `override` and give the new method another name.

```ppl
class Base {
  public virtual run(): string { "base" }
}
class Child extends Base {
  public override run(): string { "child" }
}
```
