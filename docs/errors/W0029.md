# W0029: an `async` function has no `await`

An `async` function that never awaits has no reason to be `async`: callers have to await a promise for a value that was ready at once. (Async generators and empty bodies are exempt.) The rule is off by default; turn it on with `"lint": { "requireAwait": true }` in `project.json`.

```ts
async function answer(): Promise<int> {
  42
}
println(await answer())
```

Remove `async`, or await what it waits for:

```ts
function answer(): int {
  42
}
println(answer())
```
