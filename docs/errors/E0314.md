# E0314: tuple index that isn't a constant in range

Tuple elements can have different types, so the index must be a constant the compiler can
check, and it must be smaller than the tuple's length. A variable or out-of-range index
would leave the element's type unknown.

```ppl
const t: [string, i32] = ["a", 1]
const u = t[2]
```

Use a constant index within the tuple, or destructure it.

```ppl
const t: [string, i32] = ["a", 1]
const u = t[1]
const [name, n] = t
```
