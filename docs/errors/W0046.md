# W0046: a constructor does nothing the default one wouldn't

An empty constructor, or one that only passes its parameters to `super`, does what the default constructor does. (Private and protected constructors, and ones with parameter properties, do something.) The rule is off by default; turn it on with `"lint": { "uselessConstructor": true }` in `project.json`.

```ts
class Shape {
  constructor() {}
  public name(): string { "shape" }
}
println(new Shape().name())
```

Remove it:

```ts
class Shape {
  public name(): string { "shape" }
}
println(new Shape().name())
```
