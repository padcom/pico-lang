# E0324: `new` of an abstract class

An abstract class can't be instantiated: it may have methods without a body. Only concrete
subclasses that implement every abstract method can be created with `new`.

```ts
abstract class Shape {
  public abstract area(): f64
}
const s = new Shape()
```

Create an instance of a concrete subclass instead.

```ts
abstract class Shape {
  public abstract area(): f64
}
class Square extends Shape {
  constructor(public side: f64) { super() }
  public override area(): f64 { side * side }
}
const s: Shape = new Square(2)
```
