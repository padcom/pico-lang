# E0009: malformed multiline string literal

A `'''`, `"""` or ```` ``` ```` multiline literal whose layout ppl can't make sense of.
Multiline literals strip the first and last line breaks and the indentation common to all
lines. The compiler doesn't emit this code at the moment: an unclosed multiline literal is
reported as E0001 or E0007.

```ppl ignore
const help = """
    Usage: ppl <command>
```

Close the literal with the same tripled delimiter, on a line of its own.

```ppl ignore
const help = """
    Usage: ppl <command>
    """
```
