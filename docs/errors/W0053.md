# W0053: operators of different precedence are mixed without parentheses

Operators of one family (arithmetic, bitwise, comparison, logical) with different precedence, mixed without parentheses, make the reader remember the precedence table. The rule is off by default; turn it on with `"lint": { "mixedOperators": true }` in `project.json`.

```ts
const a = true
const b = false
const c = true
println(a && b || c)
```

Add parentheses to show the order:

```ts
const a = true
const b = false
const c = true
println((a && b) || c)
```
