# E0342: an unsafe operation outside `unsafe` code

Raw pointers, calls to `extern` functions that take pointers, and similar operations can
break memory safety. pico allows them only inside an `unsafe { … }` block or `unsafe`
function, so the places that need careful review are marked in the code.

```ts
extern "C" {
  function memset(p: ptr<u8>, c: c_int, n: usize): ptr<u8>
}
const buf: u8[] = [1, 2, 3]
memset(ptr.of(buf[0]), 0 as c_int, 3 as usize)
```

Wrap the operation in `unsafe { … }` after checking that it's correct.

```ts
extern "C" {
  function memset(p: ptr<u8>, c: c_int, n: usize): ptr<u8>
}
const buf: u8[] = [1, 2, 3]
unsafe {
  memset(ptr.of(buf[0]), 0 as c_int, 3 as usize)
}
```
