# E0351: a comptime-only operation outside comptime code

Some operations exist only while compiling, such as `comptime.readFile`, which reads a file
of the project into the program. At run time there is no compiler to perform them, so
they're only allowed inside `comptime` code.

```ts
const text = comptime.readFile("notes.txt")
```

Wrap the expression in `comptime` (a `comptime const`), or use the run-time equivalent
(`std/fs`'s `readText`).

```ts
comptime const SIZE = 4 * 1024
println(SIZE)
```
