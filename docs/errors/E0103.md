# E0103: positional argument after a named argument

A call that passes a positional argument after a named one. Positional arguments bind
parameters in order, so once a name has been used pico can't tell which parameter a later
positional argument is meant for.

```ts
function area(width: i64, height: i64): i64 { width * height }
println(area(width: 2, 3))
```

Give all positional arguments first, or name the rest too.

```ts
function area(width: i64, height: i64): i64 { width * height }
println(area(width: 2, height: 3))
```
