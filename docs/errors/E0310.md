# E0310: invalid format spec

The format spec after `:` in a template placeholder doesn't fit the value's type or isn't a
valid spec: a precision on an integer, a hex format on a string, an unknown type letter.
Specs are checked at compile time so formatting can't fail at run time.

```ts
println(`${42:.2}`)
```

Use a spec the type supports, for example a precision only on floats.

```ts
println(`${42.0:.2}`)
println(`${42:5}`)
```
