# E0100: unexpected token

The parser found a token that can't appear at this point: a missing operand, a keyword in the
wrong place, an operator ppl doesn't have (such as `===`). The message says what was expected.
Parsing continues after the error, so later errors may be follow-ups of this one.

```ts
const a = 1
const b = a === 1
```

Write what the grammar expects there. ppl has no `===`; `==` already compares without
conversions.

```ts
const a = 1
const b = a == 1
println(b)
```
