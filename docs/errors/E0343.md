# E0343: a `@pod` struct with a field that isn't plain data

A `@pod` ("plain old data") struct can be copied byte for byte, written to memory or passed
to C as is. That only works when every field is plain data too: numbers, `bool`, fixed-size
arrays and other `@pod` structs. Strings, arrays and class references are managed by the
runtime and aren't.

```ts
@pod struct Record {
  id: i32
  name: string
}
```

Use only plain-data fields (for text, a fixed-size byte array), or drop `@pod`.

```ts
@pod struct Record {
  id: i32
  name: [u8; 16]
}
```
