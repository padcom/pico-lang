# W0013: a declaration hides a variable of an enclosing scope

A declaration with the name of a variable, parameter, function or import of an enclosing scope hides it, and code meant for the outer one silently gets the inner one. The rule is off by default; turn it on with `"lint": { "shadow": true }` in `project.json`.

```ts
const limit = 10

function clamp(limit: i32, x: i32): i32 {
  if (x > limit) limit else x
}
println(clamp(5, 7))
```

Give it a name of its own:

```ts
const limit = 10

function clamp(max: i32, x: i32): i32 {
  if (x > max) max else x
}
println(clamp(5, 7) + limit)
```
