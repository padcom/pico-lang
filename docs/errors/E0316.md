# E0316: array or tuple literal with the wrong number of elements

A literal or pattern has a different number of elements than its fixed-size type: a
`[i32; 2]` array or a two-element tuple given three. The length of these types is part of
the type, so it is checked at compile time.

```ppl
const pair: [i32; 2] = [1, 2, 3]
```

Give exactly as many elements as the type says, or change the type.

```ppl
const pair: [i32; 2] = [1, 2]
const triple: [i32; 3] = [1, 2, 3]
```
