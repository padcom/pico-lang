# W0052: parentheses that change nothing

Parentheses around a variable, literal, call or member read, doubled parentheses, and parentheses around a whole initializer, argument, element, field value, returned value or condition change nothing. Parentheses that group operators are left to `mixedOperators`. The rule is off by default; turn it on with `"lint": { "extraParens": true }` in `project.json`.

```ts
const n = (3)
println(n)
```

Remove them:

```ts
const n = 3
println(n)
```
