# W0039: two string literals are joined with `+`

Two string literals joined with `+` on one line are one string. (Joining them across lines, to keep lines short, is fine.) The rule is off by default; turn it on with `"lint": { "uselessConcat": true }` in `project.json`.

```ts
println("Hello, " + "world")
```

Write one string:

```ts
println("Hello, world")
```
