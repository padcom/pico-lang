# E0306: recursive function without a return type

A function that calls itself (directly or through others) must declare its return type. ppl
infers return types from the body, and a recursive body would need the type it is still
computing.

```ppl
function fact(n: i64) {
  if (n <= 1) 1 else n * fact(n - 1)
}
```

Annotate the return type.

```ppl
function fact(n: i64): i64 {
  if (n <= 1) 1 else n * fact(n - 1)
}
```
