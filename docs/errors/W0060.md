# W0060: a string uses the other kind of quotes

Strings use one kind of quotes: `'single'` (the default, `true` or `"single"`) or `"double"`. A string may use the other kind to avoid escaping a quote inside it. With `"double"`, a one-character `'x'` is left alone, since it may be a `char`. The rule is off by default; turn it on with `"lint": { "quotes": true }` (or `"double"`) in `project.json`.

```ts
println("hello")
```

Use single quotes (with the default):

```ts
println('hello')
```
