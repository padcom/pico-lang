# W0020: a generator has no `yield`

A generator without `yield` produces nothing. (An empty generator is allowed.) The rule is off by default; turn it on with `"lint": { "requireYield": true }` in `project.json`.

```ts
function* numbers(): Iterator<i32> {
  println("start")
}
for (const n of numbers()) println(n)
```

Yield its values:

```ts
function* numbers(): Iterator<i32> {
  println("start")
  yield 1
}
for (const n of numbers()) println(n)
```
