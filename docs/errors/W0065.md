# W0065: a `match` arm can never match

The arms before it, without `if` guards, already match everything this arm does, so it never runs: a repeated case, a case after `_`, or a subclass after its base class. Remove it, or move it before the arm that covers it. The rule is on by default; turn it off with `"lint": { "unreachableArm": false }` in `project.json`.

```ts
class Animal {}
class Dog extends Animal {}

function name(a: Animal): string {
  match (a) {
    x: Animal => "animal",
    d: Dog => "dog",   // never: every Dog is an Animal
  }
}
```

Put the more specific arm first:

```ts
class Animal {}
class Dog extends Animal {}

function name(a: Animal): string {
  match (a) {
    d: Dog => "dog",
    x: Animal => "animal",
  }
}
```
