# W0011: a line has more statements than the maximum

Several statements on one line are easy to miss. The default maximum is 2. The rule is off by default; turn it on with `"lint": { "maxStatementsPerLine": true }`, or give another maximum (`"maxStatementsPerLine": n`) in `project.json`.

```ts
const a = 1; const b = 2; const c = 3
println(a + b + c)
```

Put each statement on a line of its own:

```ts
const a = 1
const b = 2
const c = 3
println(a + b + c)
```
