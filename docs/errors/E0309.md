# E0309: no such member

A field, method or property is accessed on a value whose type doesn't have it. ppl types are
nominal and closed: a struct or class has exactly the members it declares, and members can't
be added at run time.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, y: 2 }
const z = p.z
```

Use a member the type declares (the message suggests close spellings), or add it to the type.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, y: 2 }
const y = p.y
```
