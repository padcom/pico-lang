# E0357: reactive state used where it isn't allowed

A `reactive` binding (spec §16.1) holds a reactive cell, and some places can't hold one: a
`reactive` binding needs an initial value and a plain name (not a destructuring pattern), a
`let` can't hold a `Reactive<T>` (assigning to it would be ambiguous: rebinding or writing the
value), and a read-only `computed` can't be assigned.

```ts
reactive count: int
count = 1
```

Give the binding its initial value:

```ts
reactive count = 0
count = 1
```
