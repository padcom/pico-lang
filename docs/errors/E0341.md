# E0341: import of a module that can't be found

An import names a relative file (`./geo`, without the extension), a `std/…` module, a
dependency from `project.json`, or a `js:`/`c:` module. This one matches none of them: the
file doesn't exist, the path is wrong, or the dependency isn't declared.

```ts
import { dot } from "./geometry"
println(dot(1, 2))
```

Fix the path, create the module, or add the dependency to `project.json` (`pico add`).

```ts
import { clamp } from "std/math"
println(clamp(5.0, 0.0, 1.0))
```
