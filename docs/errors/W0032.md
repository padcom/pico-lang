# W0032: a promise callback wraps its result in `Promise.resolve`/`reject`

A `then`, `catch` or `finally` callback already produces a promise: wrapping its result in `Promise.resolve` (or an error in `Promise.reject`) adds nothing. The rule is off by default; turn it on with `"lint": { "promiseReturnWrap": true }` in `project.json`.

```ts
async function load(): Promise<int> { 1 }
await load().then((v: int) => Promise.resolve(v + 1))
```

Return the value itself:

```ts
async function load(): Promise<int> { 1 }
await load().then((v: int) => v + 1)
```
