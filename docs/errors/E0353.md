# E0353: a `comptime` argument that isn't a constant

A `comptime` type parameter (like the `N` of `zeros<comptime N: i32>`) is fixed when the
program is compiled, so its argument has to be a constant expression. A variable only has a
value at run time.

```ts
function zeros<comptime N: i32>(): [f32; N] { [0; N] }
let k = 3
const a = zeros<k>()
```

Pass a literal, or use a run-time sized array (`f32[]`) when the size is only
known while running.

```ts
function zeros<comptime N: i32>(): [f32; N] { [0; N] }
const a = zeros<3>()
println(a.length)
```
