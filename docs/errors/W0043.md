# W0043: an `else` block holds only an `if`

An `else` block holding only an `if` is an `else if` with an extra level of nesting. The rule is off by default; turn it on with `"lint": { "lonelyIf": true }` in `project.json`.

```ts
const n = 3
if (n > 5) {
  println("big")
} else {
  if (n > 1) println("medium")
}
```

Write `else if`:

```ts
const n = 3
if (n > 5) {
  println("big")
} else if (n > 1) {
  println("medium")
}
```
