# E0356: a module or feature that isn't available on the target

Not every module exists on every target: a browser program has no file system, processes or
HTTP server, and `js:` modules and `std/js` exist only in the browser. Importing one on a
target that lacks it is an error rather than a crash at run time.

```ts
import { document } from "js:dom"
document.title = "hello"
```

Use a module the target has, or put the platform-specific code in a platform file
(`x.wasm.ppl`, `x.linux.ppl`, …) or behind `comptime if (target.os == …)`.

```ts
println("hello")
```
