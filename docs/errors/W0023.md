# W0023: an `else if` repeats an earlier condition

An `else if` whose condition was already tested earlier in the chain (also as one side of an `||`) can never run. The rule is off by default; turn it on with `"lint": { "dupeElseIf": true }` in `project.json`.

```ts
const n = 3
if (n > 5) {
  println("big")
} else if (n > 5) {
  println("bigger")
}
```

Fix the condition:

```ts
const n = 3
if (n > 5) {
  println("big")
} else if (n > 1) {
  println("bigger")
}
```
