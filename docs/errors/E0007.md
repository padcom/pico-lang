# E0007: unterminated template literal

A `` ` `` template (or a `${` substitution inside one) that isn't closed before the end of the
file. Templates may span lines, so a missing backtick or `}` swallows everything after it;
ppl reports where the template starts.

```ppl
const name = "Ada"
const greeting = `hello ${name
println(greeting)
```

Close the substitution with `}` and the template with a backtick.

```ppl
const name = "Ada"
const greeting = `hello ${name}`
println(greeting)
```
