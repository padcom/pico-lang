# E0318: pattern that can't match the matched value's type

A pattern in `match` or destructuring can never match the value: a type test for a type the
value can't have, a string range, an array pattern against a number. Such an arm would be
dead code, and usually points at a mistake in the pattern.

```ts
function f(n: i32): i32 {
  match (n) { x: string => 1, _ => 2 }
}
```

Use a pattern that fits the matched type.

```ts
function f(n: i32): i32 {
  match (n) { 0 => 1, _ => 2 }
}
```
