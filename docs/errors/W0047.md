# W0047: a variable is initialized from a field of the same name

A variable initialized from a field of the same name (`const x = p.x`) can be destructured (`const { x } = p`). The rule is off by default; turn it on with `"lint": { "preferDestructuring": true }` in `project.json`.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, y: 2 }
const x = p.x
println(x)
```

Destructure it:

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, y: 2 }
const { x } = p
println(x)
```
