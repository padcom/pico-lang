# W0042: a `function` expression is assigned to a variable

A `function` expression stored in a variable is a function declaration written the long way. (Arrow functions in variables are fine.) The rule is off by default; turn it on with `"lint": { "funcStyle": true }` in `project.json`.

```ts
const square = function (n: i32): i32 { n * n }
println(square(3))
```

Declare the function:

```ts
function square(n: i32): i32 { n * n }
println(square(3))
```
