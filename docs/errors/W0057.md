# W0057: a multi-line conditional expression doesn't put each part on its own line

A conditional expression that spans several lines puts the condition, the `?` branch and the `:` branch on lines of their own. The rule is off by default; turn it on with `"lint": { "multilineTernary": true }` in `project.json`.

```ts
const n = 3
const size = n > 1 ? "big"
  : "small"
println(size)
```

One line each:

```ts
const n = 3
const size = n > 1
  ? "big"
  : "small"
println(size)
```
