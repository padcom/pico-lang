# W0008: blocks are nested deeper than the maximum

`if`, loops, `switch`, `match` and `try` nested deeply inside one function are hard to follow. An `else if` counts as its `if`, and a closure starts again at 0. The default maximum is 2. The rule is off by default; turn it on with `"lint": { "maxDepth": true }`, or give another maximum (`"maxDepth": n`) in `project.json`.

```ts
function count(rows: i32[][]): i32 {
  let n = 0
  for (const row of rows) {
    for (const x of row) {
      if (x > 0) n += 1
    }
  }
  n
}
println(count([[1, -1], [2]]))
```

Move the inner part into a function of its own:

```ts
function positives(row: i32[]): i32 {
  let n = 0
  for (const x of row) {
    if (x > 0) n += 1
  }
  n
}

function count(rows: i32[][]): i32 {
  let n = 0
  for (const row of rows) n += positives(row)
  n
}
println(count([[1, -1], [2]]))
```
