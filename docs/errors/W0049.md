# W0049: a comparison puts the literal first

A comparison reads more naturally with the value being tested first and the literal second. The rule is off by default; turn it on with `"lint": { "yoda": true }` in `project.json`.

```ts
const n = 3
if (5 < n) println("big")
```

Put the literal second:

```ts
const n = 3
if (n > 5) println("big")
```
