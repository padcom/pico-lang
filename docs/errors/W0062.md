# W0062: a doc comment's layout is off

A doc comment's layout: in `/** … */`, each line's `*` under the first `*` of `/**`, one `*` per line, no text on the opening or closing line of a multi-line block, and one space after `*` (outside `@example`); in any doc comment, one blank line between the description and the tags, and none between tags. The rule is off by default; turn it on with `"lint": { "docFormat": true }` in `project.json`.

```ts
/** Adds two numbers.
 * @param a the first
 * @param b the second
 * @returns the sum */
function add(a: i32, b: i32): i32 { a + b }
println(add(1, 2))
```

Lay it out as a block:

```ts
/**
 * Adds two numbers.
 *
 * @param a the first
 * @param b the second
 * @returns the sum
 */
function add(a: i32, b: i32): i32 { a + b }
println(add(1, 2))
```
