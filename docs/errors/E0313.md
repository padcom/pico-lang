# E0313: object literal without a known struct or map type

An object literal `{ … }` has no struct name and nothing around it says which struct it builds.
pico has no anonymous object types; a literal needs a struct name or an expected type from an
annotation, a parameter or a return type.

```ts
struct Point { x: i32; y: i32 }
const p = { x: 1, y: 2 }
```

Name the struct, or annotate the variable.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, y: 2 }
const q: Point = { x: 3, y: 4 }
```

Where a `Map<K, V>` is expected, an object literal builds the map instead (`const env:
Map<string, string> = { LANG: "C" }`). String keys (`"x": 1`), computed keys (`[k]: v`) and
spreads (`...m`) only build maps, so they're this error in a struct literal or without an
expected type.
