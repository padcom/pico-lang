# W0017: a variable is assigned to itself

Assigning a variable or field to itself changes nothing. The rule is off by default; turn it on with `"lint": { "selfAssign": true }` in `project.json`.

```ts
let x = 1
let y = 2
x = x
println(x + y)
```

Assign what you meant:

```ts
let x = 1
let y = 2
x = y
println(x + y)
```
