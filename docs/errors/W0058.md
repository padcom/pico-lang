# W0058: a comment doesn't start with a space

A space after the comment marker (`//`, `///`, `/*`, `/**`) makes comments easier to read. The rule is off by default; turn it on with `"lint": { "spacedComment": true }` in `project.json`.

```ts
//the answer
println(42)
```

Add the space:

```ts
// the answer
println(42)
```
