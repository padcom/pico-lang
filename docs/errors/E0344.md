# E0344: a reference allocated in an arena outlives it

Everything allocated inside an `arena { … }` block is freed at once when the block ends. A
reference to such a value can't leave the block: not as its result, not stored in an outer
variable, object or array, and not returned from the function.

```ppl
const parts = arena {
  "a,b".split(",")
}
```

Copy out what you need as plain values (numbers, a new string built outside), or allocate
the value outside the arena.

```ppl
const count = arena {
  "a,b".split(",").length
}
println(count)
```
