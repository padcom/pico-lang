# E0344: a reference allocated in an arena outlives it

Everything allocated inside an `arena { … }` block is freed at once when the block ends. A
reference to such a value can't leave the block: not as its result, not stored in an outer
variable, object or array, and not returned from the function.

```ts
const parts = arena {
  "a,b".split(",")
}
```

Copy out what you need as plain values (numbers, a new string built outside), or allocate
the value outside the arena.

```ts
const count = arena {
  "a,b".split(",").length
}
println(count)
```

A generator or async function can't `yield` or `await` inside an `arena` block either: while
it's suspended, its frame would keep the arena's objects and other code would run with the
arena still open. End the arena before suspending.

```ts
async function total(): Promise<int> {
  let n = 0
  arena {
    n = "a,b".split(",").length
  }
  await Promise.resolve(0)   // after the arena: fine
  n
}
```
