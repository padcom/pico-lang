# W0010: callbacks are nested deeper than the maximum

Functions passed as arguments, nested inside each other, read from the inside out. The default maximum is 2. The rule is off by default; turn it on with `"lint": { "maxNestedCallbacks": true }`, or give another maximum (`"maxNestedCallbacks": n`) in `project.json`.

```ts
const out = [1].map((a: int) => [2].map((b: int) => [3].map((c: int) => a + b + c)))
println(out.length)
```

Name the inner callback and declare it outside:

```ts
function sums(a: int, b: int): int[] {
  [3].map((c: int) => a + b + c)
}
const out = [1].map((a: int) => [2].map((b: int) => sums(a, b)))
println(out.length)
```
