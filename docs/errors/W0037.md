# W0037: `x = x op y` where `x op= y` would do

`x = x + y` repeats `x`; `x += y` says the same more briefly (for arithmetic and bitwise operators). The rule is off by default; turn it on with `"lint": { "operatorAssignment": true }` in `project.json`.

```ts
let total = 1
total = total * 3
println(total)
```

Use the compound assignment:

```ts
let total = 1
total *= 3
println(total)
```
