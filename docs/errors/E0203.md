# E0203: name declared twice in the same scope

Two declarations of the same name in one scope. ppl doesn't let a later `const`, `let` or
function silently replace an earlier one in the same block.

```ppl
const count = 1
const count = 2
println(count)
```

Rename one of them, or assign to a `let` instead of redeclaring it.

```ppl
let count = 1
count = 2
println(count)
```
