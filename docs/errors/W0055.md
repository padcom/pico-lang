# W0055: braces aren't placed in the one true brace style

The "one true brace style": `{` on the line of what it opens, `}` on the line of the `else`, `catch` or `finally` that follows, and the statements of a multi-line block on lines of their own. One-line blocks are fine. The rule is off by default; turn it on with `"lint": { "braceStyle": true }` in `project.json`.

```ts
const n = 3
if (n > 1) {
  println("big")
}
else {
  println("small")
}
```

Put `else` on the line of the `}`:

```ts
const n = 3
if (n > 1) {
  println("big")
} else {
  println("small")
}
```
