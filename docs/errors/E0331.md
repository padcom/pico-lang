# E0331: `tailcall` that can't be a guaranteed tail call

`tailcall f(…)` promises that the call reuses the current stack frame, so deep recursion can't
overflow the stack. ppl checks the promise: the call has to be the last thing the function
does (nothing may happen to its result afterwards), and the callee has to return the same
type as the caller.

```ppl
function count(n: i64): i64 {
  if (n == 0) 0 else tailcall count(n - 1) + 1
}
```

Make the call the function's result, for example by carrying the running value in an
accumulator parameter, or drop `tailcall` and accept an ordinary call.

```ppl
function count(n: i64, acc: i64): i64 {
  if (n == 0) return acc
  return tailcall count(n - 1, acc + 1)
}
println(count(10, 0))
```
