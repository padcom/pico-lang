# E0330: type argument that doesn't meet its bound

A type argument, given or inferred, doesn't satisfy a bound of its type parameter, for example
`T extends Comparable<T>` with a class that has no ordering. Bounds let the generic code use
the operations they promise, so every instantiation must provide them.

```ts
function max<T extends Comparable<T>>(a: T, b: T): T { if (a.compareTo(b) >= 0) a else b }
class P { constructor(public x: i32) {} }
const m = max(new P(1), new P(2))
```

Use a type that meets the bound, or make the type implement it (`@derive(Ord)` for classes).

```ts
function max<T extends Comparable<T>>(a: T, b: T): T { if (a.compareTo(b) >= 0) a else b }
const m = max(1, 2)
```
