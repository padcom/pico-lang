# W0034: a `let` is never reassigned

A `let` that's never reassigned can be a `const`, which tells the reader it won't change. The rule is off by default; turn it on with `"lint": { "preferConst": true }` in `project.json`.

```ts
let greeting = "hi"
println(greeting)
```

Declare it with `const`:

```ts
const greeting = "hi"
println(greeting)
```
