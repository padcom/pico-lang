# E0006: unexpected character

A character that can't start any token: it isn't part of an identifier, number, string,
operator or punctuation. It's usually a stray symbol pasted from elsewhere, or a character from
another language's syntax.

```ts
const price = 5 € 2
println(price)
```

Remove the character, or put it inside a string if it's meant as text.

```ts
const price = 5
println(`${price} €`)
```
