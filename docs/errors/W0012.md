# W0012: a line is longer than the maximum

Long lines are hard to read side by side and in reviews. The default maximum is 130 characters. The rule is off by default; turn it on with `"lint": { "maxLen": true }`, or give another maximum (`"maxLen": n`) in `project.json`.

```ts
println("a fairly long message that keeps going and going, well past the point where a reader would like it to stop, and then some more")
```

Break the line:

```ts
const message = "a fairly long message that keeps going and going"
println(`${message} well past the point where a reader would like it to stop`)
```
