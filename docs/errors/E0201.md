# E0201: cannot find a name in this scope

A name that isn't declared where it's used: a typo, a variable used outside the block that
declares it, or a declaration from another module that isn't imported.

```ppl
const total = 3
println(totl)
```

Use the declared name (the message suggests close spellings), declare it, or import it
(`import { name } from "./module"`).

```ppl
const total = 3
println(total)
```
