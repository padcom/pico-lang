# W0031: `then`/`catch`/`finally` or a callback where `await` would do

`.then`, `.catch` and `.finally` chains, `callback`/`cb` parameters and error-first callbacks (`(err, value) => …`) are harder to follow than `await` with `try`/`catch`. The rule is off by default; turn it on with `"lint": { "preferAwait": true }` in `project.json`.

```ts
async function load(): Promise<int> { 1 }
load().then((v: int) => println(v))
```

Await the promise:

```ts
async function load(): Promise<int> { 1 }
println(await load())
```
