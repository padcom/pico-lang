# E0319: use of a private member outside its class

A class member without `public` is private: only the class's own code can use it. ppl
defaults to private so a class's public surface is always written out.

```ts
class Counter {
  count: i64 = 0
}
const c = new Counter()
println(c.count)
```

Mark the member `public`, or expose it through a public method or getter.

```ts
class Counter {
  count: i64 = 0
  public get value(): i64 { count }
}
const c = new Counter()
println(c.value)
```
