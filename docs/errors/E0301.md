# E0301: literal out of range for its type

A numeric or character literal that doesn't fit the type it gets: `256` as a `u8`, `-1u8`, or a
`char` literal with more than one character. ppl rejects these at compile time rather than
wrapping or truncating the value silently.

```ppl
const level: u8 = 256
```

Use a value inside the type's range, or pick a wider type.

```ppl
const level: u16 = 256
const small: u8 = 255
```
