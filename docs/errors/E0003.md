# E0003: invalid escape sequence

A `\` in a string, template or char literal that isn't followed by a known escape. pico accepts
`\n \r \t \0 \b \f \v \\ \' \" \` \$`, `\xHH`, `\uHHHH` and `\u{…}`; anything else is an
error rather than being passed through, so a typo like `\d` doesn't go unnoticed.

```ts
const path = "C:\data\q.txt"
println(path)
```

Escape the backslash itself (`\\`), or use the escape you meant.

```ts
const path = "C:\\data\\q.txt"
println(path)
```
