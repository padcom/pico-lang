# E0210: struct that contains itself by value

A struct with a field of its own type, directly or through other structs (`A` holds a `B` that
holds an `A`). Structs are stored inline, so such a struct would need infinite size. Classes
are references and may refer to themselves.

```ts
struct Node {
  value: i64
  next: Node
}
```

Make the field optional (`Node?`, which ends the chain), use an array, or use a class.

```ts
class Node {
  constructor(public value: i64, public next: Node?) {}
}
const list = new Node(1, null)
println(list.value)
```
