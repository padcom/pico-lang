# E0105: modifier not allowed here

A modifier (`public`, `private`, `readonly`, `static`, `override`, …) that's repeated or that
doesn't apply where it's written. Each modifier may appear once per declaration, and some can't
be combined or used on that kind of member.

```ts
class Point {
  public public x: i64 = 0
}
println(new Point().x)
```

Remove the duplicate or misplaced modifier.

```ts
class Point {
  public x: i64 = 0
}
println(new Point().x)
```
