# E0347: a constant expression that always panics (overflow, division by zero, …)

The compiler folds constant expressions. When one would always panic at run time (an
integer overflow, a division by zero, a shift by too many bits, a conversion out of range)
it's reported at compile time instead, even in code that never runs.

```ts
const d = 255u8 + 1u8
```

Fix the arithmetic: use a wider type, a value in range, or a checked/wrapping operation if
the overflow is intended.

```ts
const d = 255u16 + 1u16
println(d)
```
