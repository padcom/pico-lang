# E0336: a checked error is neither caught nor declared in `throws`

A method's `throws` list is part of its type. When a call can throw a checked error, the
caller either catches it or lists it in its own `throws`, so every error a method can raise
is visible in its signature. (Top-level functions without a `throws` clause infer it.)

```ts
class ParseError extends Error {}
function parse(s: string): int throws ParseError {
  if (s == "") throw new ParseError("empty") else 1
}
class Runner {
  public run(): void { println(parse("x")) }
}
```

Catch the error with `try`/`catch`, or add it to the caller's `throws`.

```ts
class ParseError extends Error {}
function parse(s: string): int throws ParseError {
  if (s == "") throw new ParseError("empty") else 1
}
class Runner {
  public run(): void throws ParseError { println(parse("x")) }
}
```
