# E0346: an inline worker's function captures variables

A worker runs on another thread with its own memory, so the function it runs can't refer to
variables of the code that starts it. An inline worker's function (`new Worker(fn)`,
`parallelMap`'s callback) may only use its parameters and top-level functions and types,
not even outer constants.

```ts
let factor = 3
const w = new Worker((n: int): int => n * factor)
```

Pass the value in as data (a parameter or part of the message), or write it into the
worker's function.

```ts
const w = new Worker((n: int): int => n * 3)
```
