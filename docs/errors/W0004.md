# W0004: a blank line is missing before a statement or declaration

A blank line before a statement `if`, `switch` and `match`, and before a function, method,
constructor, getter or setter, separates the steps of the code; the first one in a block or
type body is exempt. The rule is off by default; turn it on with
`"lint": { "blankLines": true }`, or pick the constructs with `{ "blankLines": { "before":
["if", "function"] } }`.

```ts
function check(a: i32) {
  const b = a * 2
  if (b > 2) {
    println(b)
  }
}
check(1)
```

Add a blank line before the construct (a comment that belongs to it goes after the blank
line).

```ts
function check(a: i32) {
  const b = a * 2

  if (b > 2) {
    println(b)
  }
}
check(1)
```
