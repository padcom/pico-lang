# E0001: unterminated string literal

A `'…'` or `"…"` string that reaches the end of the line (or a `'''`/`"""` string that reaches
the end of the file) without its closing quote. A one-line string can't span lines; ppl reports
it where it starts so the rest of the file still parses.

```ts
const greeting = "hello
println(greeting)
```

Close the string on the same line. For text over several lines use a multiline literal
(`"""…"""`) or `\n`.

```ts
const greeting = "hello"
println(greeting)
```
