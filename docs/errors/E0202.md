# E0202: name used before its declaration

A `const` or `let` binding used before the line that declares it. Bindings come into scope
where they're declared, so their value exists only from then on. Top-level functions are
exempt: they can be called anywhere in their module.

```ts
println(limit)
const limit = 10
```

Move the declaration above its first use.

```ts
const limit = 10
println(limit)
```
