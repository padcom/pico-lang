# E0302: wrong number of arguments

A call passes more or fewer arguments than the function takes. ppl has no implicit `undefined`
for missing arguments; a parameter that may be left out needs a default value.

```ts
function add(a: i32, b: i32): i32 { a + b }
add(1)
```

Pass every argument, or give the parameter a default (`b: i32 = 0`).

```ts
function add(a: i32, b: i32 = 0): i32 { a + b }
add(1)
add(1, 2)
```
