# E0345: `await` outside an async function

`await` suspends the current function until a promise settles. Only an `async` function can
be suspended, so `await` is only allowed inside one (and at the top level of the entry
module).

```ts
async function one(): Promise<int> { 1 }
function sync(): void {
  await one()
}
```

Make the function `async` (it then returns a `Promise`), or move the `await` to a caller that
is async.

```ts
async function one(): Promise<int> { 1 }
async function run(): Promise<void> {
  println(await one())
}
```
