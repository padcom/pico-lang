# W0051: a body without braces doesn't end on its statement's line

A body without braces on another line than its statement (`if (…)` and the body below it) is easy to misread when a line is added. On one line, braces aren't needed. The rule is off by default; turn it on with `"lint": { "curly": true }` in `project.json`.

```ts
const n = 3
if (n > 1)
  println("big")
```

Add braces, or put it on the statement's line:

```ts
const n = 3
if (n > 1) println("big")
```
