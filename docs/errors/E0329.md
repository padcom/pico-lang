# E0329: type argument that can't be inferred

A generic function or type is used without explicit type arguments, and nothing in the
arguments or the expected type determines one of them. ppl doesn't default a type
parameter to some top type; each must be known.

```ppl
function make<T>(): T[] { [] }
const xs = make()
```

Pass the type argument explicitly.

```ppl
function make<T>(): T[] { [] }
const xs = make<i32>()
```
