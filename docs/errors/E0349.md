# E0349: comptime evaluation exceeded its step limit

Comptime code runs inside the compiler, so an endless loop there would hang the build. Each
comptime evaluation stops after a step limit (10 million by default, set with
`@comptimeLimit(n)`) and reports where it was.

```ts
function spin(): int {
  loop {}
}
comptime const FOREVER = spin()
```

Make the computation finish, or raise the limit with `@comptimeLimit(n)` if it is just long.

```ts
function sum(n: int): int {
  let s = 0
  for (const i of 0..n) s += i
  s
}
comptime const TOTAL = sum(100)
println(TOTAL)
```
