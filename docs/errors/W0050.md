# W0050: a getter and its setter aren't next to each other, getter first

A getter and the setter of the same property belong together, getter first. The rule is off by default; turn it on with `"lint": { "groupedAccessors": true }` in `project.json`.

```ts
class Box {
  private stored: i32 = 0
  public set size(v: i32) { stored = v }
  public get size(): i32 { stored }
}
const b = new Box()
b.size = 2
println(b.size)
```

Put the setter right after its getter:

```ts
class Box {
  private stored: i32 = 0
  public get size(): i32 { stored }
  public set size(v: i32) { stored = v }
}
const b = new Box()
b.size = 2
println(b.size)
```
