# E0337: `throw` of a value that isn't an `Error`

`throw` takes an instance of an `Error` class, or a struct or enum that implements
`Throwable`. Arbitrary values can't be thrown, because a `catch` has to be able to tell what
it caught and print a message for it.

```ts
struct Point {
  x: int
}
function f(): void throws Error {
  throw Point { x: 1 }
}
```

Throw an `Error` (or a subclass carrying the data you need).

```ts
class PointError extends Error {}
function f(): void throws PointError {
  throw new PointError("bad point")
}
```
