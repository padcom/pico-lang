# E0327: type that doesn't implement an interface method

A class or struct says it `implements` an interface but doesn't provide one of the
interface's methods, and the interface has no default body for it. Interfaces are nominal
contracts, so the type must implement all of them.

```ts
interface Shape { area(): f64; perimeter(): f64 }
class Half implements Shape {
  public area(): f64 { 1 }
}
```

Implement every method that has no default.

```ts
interface Shape { area(): f64; perimeter(): f64 }
class Half implements Shape {
  public area(): f64 { 1 }
  public perimeter(): f64 { 4 }
}
```
