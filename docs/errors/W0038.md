# W0038: a string is built with `+` where a template would do

A string built with `+` from literals and values is easier to read as a template. The rule is off by default; turn it on with `"lint": { "preferTemplate": true }` in `project.json`.

```ts
const name = "Ann"
println("Hello, " + name + "!")
```

Write a template:

```ts
const name = "Ann"
println(`Hello, ${name}!`)
```
