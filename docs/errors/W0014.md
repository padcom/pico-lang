# W0014: an expression's value is dropped and it has no effect

An expression whose value is dropped and that has no effect (a variable, an operation, a literal, an object created and never used) does nothing; usually something is missing, such as an assignment or a call. The rule is off by default; turn it on with `"lint": { "unusedExpressions": true }` in `project.json`.

```ts
let total = 0
function add(n: i32): void {
  total + n
}
add(1)
println(total)
```

Use the value:

```ts
let total = 0
function add(n: i32): void {
  total += n
}
add(1)
println(total)
```
