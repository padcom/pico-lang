# W0036: a destructuring, import or export renames a name to itself

A destructuring, import or export that renames a name to itself (`{ x: x }`, `a as a`) says nothing. The rule is off by default; turn it on with `"lint": { "uselessRename": true }` in `project.json`.

```ts
struct Point { x: i32; y: i32 }
const { x: x, y } = Point { x: 1, y: 2 }
println(x + y)
```

Write the name alone:

```ts
struct Point { x: i32; y: i32 }
const { x, y } = Point { x: 1, y: 2 }
println(x + y)
```
