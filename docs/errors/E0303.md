# E0303: called value is not a function

The expression before `(…)` has a type that can't be called, such as a number or a string.
Only functions, closures and values of a function type can be called.

```ts
const n = 5
const m = n(1)
```

Call a function, or drop the parentheses if you meant the value itself.

```ts
const n = 5
const double = (x: i64) => x * 2
const m = double(n)
```
