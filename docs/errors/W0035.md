# W0035: an object literal field repeats its name (`x: x`)

An object literal field whose value is a variable of the same name can be written once. The rule is off by default; turn it on with `"lint": { "objectShorthand": true }` in `project.json`.

```ts
struct Point { x: i32; y: i32 }
const x = 1
const y = 2
const p = Point { x: x, y: y }
println(p.x)
```

Write the name alone:

```ts
struct Point { x: i32; y: i32 }
const x = 1
const y = 2
const p = Point { x, y }
println(p.x)
```
