# W0021: a `for` loop's update moves its counter away from the condition

A `for` loop whose update moves its counter away from the condition's limit runs forever, or until the counter overflows. The rule is off by default; turn it on with `"lint": { "forDirection": true }` in `project.json`.

```ts
for (let i = 0; i < 3; i--) {
  println(i)
  break
}
```

Count the other way:

```ts
for (let i = 0; i < 3; i++) {
  println(i)
  break
}
```
