# W0001: a name doesn't follow the naming conventions

ppl code uses one naming style everywhere: camelCase for variables, constants, functions,
parameters and members; PascalCase for types, enum variants and type parameters. A shared
style makes code from different projects read the same. The rule is on by default; turn it
off with `"lint": { "naming": false }` in `project.json`.

```ppl
const max_size = 10
function Double_It(n: i32): i32 { n * 2 }
println(Double_It(max_size))
```

Rename to the conventional style.

```ppl
const maxSize = 10
function doubleIt(n: i32): i32 { n * 2 }
println(doubleIt(maxSize))
```
