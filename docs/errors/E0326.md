# E0326: `super(…)`/`this(…)` misplaced, missing or without a matching constructor

A constructor of a subclass must call `super(…)` (or delegate with `this(…)`) as its first
statement, with arguments that fit a constructor of the target class. The base part of the
object has to be built before the subclass's code can use it.

```ts
class A { constructor() {} }
class B extends A {
  constructor() { const x = 1; super() }
}
```

Call `super(…)` first, then run the rest of the constructor.

```ts
class A { constructor() {} }
class B extends A {
  constructor() { super(); const x = 1 }
}
```
