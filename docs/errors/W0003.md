# W0003: a function's cyclomatic complexity is above the maximum

The cyclomatic complexity counts a function's paths: 1, plus one for each `if`, `else if`,
loop, `case`, `match` arm, `catch`, conditional expression, `&&`, `||` and `??`. Functions
above the maximum are hard to read and test. The rule is off by default; turn it on with
`"lint": { "complexity": true }` (maximum 4) or `{ "complexity": { "max": n } }`.

```ts
function grade(score: i32): string {
  if (score > 90) {
    return "A"
  } else if (score > 80) {
    return "B"
  } else if (score > 70) {
    return "C"
  } else if (score > 60) {
    return "D"
  }
  "F"
}
println(grade(75))
```

Split the function, or replace the chain of conditions with data (a table or a `match`
over a computed value).

```ts
const limits = [90, 80, 70, 60]
const letters = ["A", "B", "C", "D"]

function grade(score: i32): string {
  for (const i of 0..limits.length) {
    if (score > limits[i]) return letters[i]
  }
  "F"
}
println(grade(75))
```
