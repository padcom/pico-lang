# W0045: a `return` at the end of a function does nothing

A bare `return` at the end of a function changes nothing: the function ends there anyway. The rule is off by default; turn it on with `"lint": { "uselessReturn": true }` in `project.json`.

```ts
function greet(): void {
  println("hi")
  return
}
greet()
```

Remove it:

```ts
function greet(): void {
  println("hi")
}
greet()
```
