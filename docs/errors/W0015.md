# W0015: code after `return`, `throw`, `break` or `continue` never runs

Statements after `return`, `throw`, `break` or `continue` in the same block never run. The rule is off by default; turn it on with `"lint": { "unreachable": true }` in `project.json`.

```ts
function sign(n: i32): i32 {
  if (n < 0) {
    return -1
    println("negative")
  }
  1
}
println(sign(-2))
```

Remove them, or move them before the statement that leaves:

```ts
function sign(n: i32): i32 {
  if (n < 0) {
    println("negative")
    return -1
  }
  1
}
println(sign(-2))
```
