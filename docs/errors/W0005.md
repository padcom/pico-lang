# W0005: an exported declaration has no doc comment

Exported declarations are a module's interface, and their doc comments are what `ppl doc`
and the editor show. The rule asks for a doc comment (`/** … */` or `///`, with a
description) on each one and on the public members of exported types. It's off by default;
turn it on with `"lint": { "docs": true }` in `project.json`.

```ts
export function area(w: i32, h: i32): i32 { w * h }
```

Add a doc comment that says what the declaration does (tags alone, like `@deprecated`, don't
count).

```ts
/** The area of a `w` by `h` rectangle. */
export function area(w: i32, h: i32): i32 { w * h }
```
