# E0207: parameter without a type annotation

A function parameter without a `: Type`. ppl infers the types of local variables but not of
function parameters, so a function's signature can be read (and checked) without looking at
its callers.

```ts
function double(n) { n * 2 }
println(double(2))
```

Annotate the parameter.

```ts
function double(n: i64): i64 { n * 2 }
println(double(2))
```
