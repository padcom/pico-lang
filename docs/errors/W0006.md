# W0006: a function's result is a lone variable without `return`

A function's last expression is its result, which suits a computed value (`a + b`, a call, an
`if`). When the result is a variable computed earlier, an explicit `return` makes it easier to
see what the function hands back. The rule asks for `return` there. It's off by default; turn
it on with `"lint": { "explicitReturn": true }` in `project.json`.

```ts
function total(prices: i32[]): i32 {
  let sum: i32 = 0
  for (const p of prices) sum += p
  sum
}
println(total([1, 2, 3]))
```

Return the variable with `return`:

```ts
function total(prices: i32[]): i32 {
  let sum: i32 = 0
  for (const p of prices) sum += p
  return sum
}
println(total([1, 2, 3]))
```

Arrow functions with an expression body (`(x: i32) => x`), constructors, setters, generators,
functions declared `: void` and blocks used as values (`const a = { const w = 3; w }`) are
exempt.
