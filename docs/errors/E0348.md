# E0348: comptime evaluation panicked or threw

A `comptime` expression is evaluated by the compiler. If that evaluation panics or throws,
there's no value to put in the program, so the build fails with the panic's message and a
backtrace of the comptime call.

```ts
comptime const LIMIT = panic("not configured")
```

Fix the comptime code so it produces a value (the backtrace shows where it failed).

```ts
comptime const LIMIT = 10 * 1024
println(LIMIT)
```
