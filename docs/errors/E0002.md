# E0002: unterminated block comment

A `/*` comment without a matching `*/` before the end of the file. Everything after the `/*`
would be commented out, so pico reports where the comment starts instead of silently dropping
the rest of the program.

```ts
/* compute the total
const total = 1 + 2
println(total)
```

Close the comment with `*/`, or use `//` line comments.

```ts
/* compute the total */
const total = 1 + 2
println(total)
```
