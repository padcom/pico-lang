# E0005: integer literal too large

An integer literal whose value doesn't fit in 64 bits. No integer type in ppl is wider than 64
bits, so such a literal can't have any type; it's rejected while reading the source, before
any type is chosen.

```ppl
const big = 99999999999999999999999
println(big)
```

Use a value that fits (at most `18446744073709551615` for `u64`), or a float literal if an
approximate value is enough.

```ppl
const big = 99999999999999999999999.0
println(big)
```
