# E0328: conflicting default methods from two interfaces

A type implements two interfaces that both provide a default body for the same method. ppl
doesn't pick one by declaration order; the type has to decide.

```ts
interface A { hello(): string { "A" } }
interface B { hello(): string { "B" } }
class C implements A, B {}
```

Implement the method in the type itself.

```ts
interface A { hello(): string { "A" } }
interface B { hello(): string { "B" } }
class C implements A, B {
  public hello(): string { "C" }
}
```
