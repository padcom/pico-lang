# W0026: a closure in a loop captures a variable the loop changes

A closure created in a loop that captures a `let` declared outside the loop and changed while it runs sees the variable's latest value, not the one it had when the closure was made. The rule is off by default; turn it on with `"lint": { "loopFunc": true }` in `project.json`.

```ts
const fns: (() => int)[] = []
let i = 0
while (i < 3) {
  fns.push(() => i)
  i += 1
}
println(fns[0]())
```

Copy the value into a `const` inside the loop and capture that:

```ts
const fns: (() => int)[] = []
let i = 0
while (i < 3) {
  const current = i
  fns.push(() => current)
  i += 1
}
println(fns[0]())
```
