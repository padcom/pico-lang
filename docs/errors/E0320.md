# E0320: field not definitely assigned by a constructor

A class field without an initializer isn't assigned on every path through a constructor. ppl
has no `undefined`, so every field must hold a value once construction finishes.

```ppl
class User {
  public name: string
  constructor() {}
}
```

Assign the field in every constructor (or every path of it), give it an initializer, or use a
parameter property.

```ppl
class User {
  public name: string
  constructor() { this.name = "anonymous" }
}
```
