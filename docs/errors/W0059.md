# W0059: a semicolon that changes nothing

A `;` at the end of a line, or an empty statement, changes nothing. A `;` that ends a block's last expression makes the block's value `void` and is kept, as are the ones separating statements on one line, the ones in a `for (…; …; …)` header, and one before a line starting with `(`, `[`, a template, `+`, `-` or `/`. The rule is off by default; turn it on with `"lint": { "extraSemi": true }` in `project.json`.

```ts
const n = 3;
println(n)
```

Remove it:

```ts
const n = 3
println(n)
```
