# W0028: `await` inside a loop

`await` in a loop makes each iteration wait for the previous one. When the iterations don't depend on each other, start them all and wait once. A `for await` loop's body is meant to wait and isn't reported. The rule is off by default; turn it on with `"lint": { "awaitInLoop": true }` in `project.json`.

```ts
async function load(n: int): Promise<int> { n }

async function total(ns: int[]): Promise<int> {
  let sum = 0
  for (const n of ns) {
    sum += await load(n)
  }
  sum
}
println(await total([1, 2]))
```

Start the work first and await it all after the loop:

```ts
async function load(n: int): Promise<int> { n }

async function total(ns: int[]): Promise<int> {
  const values = await Promise.all(ns.map((n: int) => load(n)))
  values.reduce((a: int, b: int) => a + b, 0)
}
println(await total([1, 2]))
```
