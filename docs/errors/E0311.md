# E0311: struct literal without all fields

A struct literal leaves out a field that has no default value. Every field of a struct must be
initialized when the struct is built; there is no implicit `undefined`.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1 }
```

Give every field a value, or give the field a default in the struct declaration.

```ts
struct Point { x: i32; y: i32 }
const p = Point { x: 1, y: 0 }
```
