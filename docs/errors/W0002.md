# W0002: a variable, parameter, private member or import is never used

A variable that's never read, a trailing parameter that's never used, a private method or an
import that nothing refers to is usually a leftover or a bug. Names starting with `_` are
exempt. The rule is on by default; turn it off with `"lint": { "unused": false }` in
`project.json`.

```ts
function area(w: i32, h: i32): i32 {
  const unusedArea = w * h
  w * w
}
println(area(2, 3))
```

Remove what isn't needed, use it, or name it with a leading `_` when it must stay.

```ts
function area(w: i32, h: i32): i32 {
  w * h
}
println(area(2, 3))
```
