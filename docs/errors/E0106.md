# E0106: `??` mixed with `&&` or `||` without parentheses

`??` combined with `&&` or `||` in one expression without parentheses. Languages disagree on
how these bind, so ppl, like TypeScript, makes the grouping explicit instead of picking a
precedence a reader might not expect.

```ppl
const a: bool? = null
const b = false
const c = a ?? b || true
```

Add parentheses around the part that should be evaluated first.

```ppl
const a: bool? = null
const b = false
const c = (a ?? b) || true
println(c)
```
