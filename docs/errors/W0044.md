# W0044: a block statement scopes nothing

A block statement that declares nothing scopes nothing: its braces only add nesting. The rule is off by default; turn it on with `"lint": { "loneBlocks": true }` in `project.json`.

```ts
const n = 3
{
  println(n)
}
```

Remove the braces:

```ts
const n = 3
println(n)
```
