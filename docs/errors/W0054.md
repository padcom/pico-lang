# W0054: a trailing comma is missing in a multi-line list or present in a one-line list

A list (array, object, arguments, parameters, pattern, import or export) whose closing bracket is on a line of its own ends with a comma, so adding an element changes one line; a one-line list doesn't. A rest element takes no comma after it. The rule is off by default; turn it on with `"lint": { "commaDangle": true }` in `project.json`.

```ts
const names = [
  "Ann",
  "Bob"
]
println(names.length)
```

Add the trailing comma:

```ts
const names = [
  "Ann",
  "Bob",
]
println(names.length)
```
