# E0104: expected a newline or `;` between statements

Two statements on one line without a `;` between them. A statement ends at a newline, a `;`
or a closing `}`; ppl doesn't guess where one statement ends and the next begins.

```ppl
const a = 1 const b = 2
println(a + b)
```

Put each statement on its own line, or separate them with `;`.

```ppl
const a = 1
const b = 2
println(a + b)
```
