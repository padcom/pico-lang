# E0354: an error reported by a decorator, or a decorator used wrongly

A decorator was applied to something it doesn't support, with arguments it doesn't accept,
or it reported an error itself (user decorators run at comptime and can reject the
declaration). The message comes from the decorator.

```ts
@derive(Eq, Show)
class A { constructor(public x: i64) {} }
```

Use the decorator as documented: `@derive` takes `Eq`, `Hash` and `Ord` only (a class gets
`toString` without deriving it).

```ts
@derive(Eq, Hash)
class A { constructor(public x: i64) {} }
println(new A(1) == new A(1))
```
