# E0101: unclosed delimiter

A `(`, `[` or `{` without its matching closer. pico reports the opening delimiter, which is
usually far from where the mistake shows up: the parser only notices at the end of the file or
at a closer of the wrong kind.

```ts
function main() {
  if (true) {
    println("hi")
}
```

Add the missing `)`, `]` or `}`.

```ts
function main() {
  if (true) {
    println("hi")
  }
}
```
