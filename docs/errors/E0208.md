# E0208: a type or built-in used as a value

A name that refers to a type (a struct, class, interface, a built-in type) used where a value
is expected. Types exist only at compile time in ppl; they can be passed only to `comptime T:
type` parameters.

```ppl
struct Point { x: f64 }
const p = Point
```

Create a value of the type instead (a struct literal, `new` for a class).

```ppl
struct Point { x: f64 }
const p: Point = { x: 1.0 }
println(p.x)
```
