# E0323: concrete class that leaves an abstract method unimplemented

A class that isn't `abstract` extends an abstract class but doesn't override all of its
`abstract` methods. Instances of a concrete class can be created, so every method must have a
body.

```ppl
abstract class Shape {
  public abstract area(): f64
}
class Square extends Shape {}
```

Override every abstract method, or mark the subclass `abstract` too.

```ppl
abstract class Shape {
  public abstract area(): f64
}
class Square extends Shape {
  constructor(public side: f64) { super() }
  public override area(): f64 { side * side }
}
```
