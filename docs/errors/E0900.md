# E0900: feature not implemented yet

The program uses a part of the language that the spec describes but this compiler version
doesn't support yet. The message names the feature. It's a limitation of the compiler, not
a mistake in the program.

```ppl
function show(a: i64): string { "int" }
function show(a: f64): string { "float" }
const f = show
```

Work around it until the feature lands; the message usually suggests how. Here: call the
function, or wrap the call in a closure.

```ppl
function show(a: i64): string { "int" }
function show(a: f64): string { "float" }
const f = (a: i64): string => show(a)
println(f(1))
```
