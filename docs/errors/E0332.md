# E0332: call that fits several overloads equally well

The arguments convert to more than one overload's parameters and none of them is a better
fit than the others. pico doesn't pick one silently, because a later change to the arguments
could quietly switch which function runs.

```ts
function show(a: i64, b: f64): string { "int first" }
function show(a: f64, b: i64): string { "float first" }
println(show(1, 2))
```

Give the arguments the types of the overload you mean (a literal suffix or `as`), so that one
overload fits better than the rest.

```ts
function show(a: i64, b: f64): string { "int first" }
function show(a: f64, b: i64): string { "float first" }
println(show(1, 2.0))
```
