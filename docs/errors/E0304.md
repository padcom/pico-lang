# E0304: operator can't be applied to these types

A unary or binary operator is used on operand types it isn't defined for, such as `true + 1`
or `<` on a type without an ordering. pico doesn't coerce `bool` to a number or guess a
conversion; each operator works only on the types that define it.

```ts
const n = true + 1
```

Convert the operand to a type the operator accepts, or use a different operation.

```ts
const n = (if (true) 1 else 0) + 1
```
