# W0033: a promise executor's parameters aren't `resolve` and `reject`

The parameters of the function given to `new Promise` are, by convention, `resolve` and `reject` (an `_` in front marks an unused one). The rule is off by default; turn it on with `"lint": { "promiseParamNames": true }` in `project.json`.

```ts
const p = new Promise<int>((ok, fail) => ok(1))
println(await p)
```

Name them `resolve` and `reject`:

```ts
const p = new Promise<int>((resolve, _reject) => resolve(1))
println(await p)
```
