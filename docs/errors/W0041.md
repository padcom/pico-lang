# W0041: a `function` expression is passed as a callback

A `function` expression passed as a callback is longer than an arrow function and doesn't see the surrounding `this`. (Generators, and functions that use `this` or call themselves by name, are exempt.) The rule is off by default; turn it on with `"lint": { "preferArrowCallback": true }` in `project.json`.

```ts
const doubled = [1, 2].map(function (n: int): int { n * 2 })
println(doubled.length)
```

Pass an arrow function:

```ts
const doubled = [1, 2].map((n: int) => n * 2)
println(doubled.length)
```
