# E0335: mutation through an `immutable` view or in a `readonly` method

An `immutable T` parameter or variable is a read-only view: nothing reached through it may be
changed, nor may methods that change the object be called on it. A `readonly` method makes
the same promise about `this`. Callers rely on it to hand out data safely.

```ts
class Scene {
  constructor(public nodes: string[]) {}
}
function render(scene: immutable Scene) {
  scene.nodes.push("x")
}
```

Only read through the view, or take a plain (mutable) `Scene` if the function has to change
it.

```ts
class Scene {
  constructor(public nodes: string[]) {}
}
function render(scene: immutable Scene) {
  println(scene.nodes.length)
}
render(new Scene(["a"]))
```
