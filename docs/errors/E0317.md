# E0317: non-exhaustive `match`

A `match` used as an expression has no arm for some possible values. pico requires every
`match` to cover all cases so that it always produces a value; the message names a value
that isn't covered.

```ts
function name(n: i32): string {
  match (n) { 0 => "zero", 1 => "one" }
}
```

Add arms for the missing cases, or a catch-all `_` arm.

```ts
function name(n: i32): string {
  match (n) { 0 => "zero", 1 => "one", _ => "many" }
}
```
