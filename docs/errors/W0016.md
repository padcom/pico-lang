# W0016: a value is compared with itself

Comparing a value with itself always gives the same result; usually the other side is a typo. The rule is off by default; turn it on with `"lint": { "selfCompare": true }` in `project.json`.

```ts
const a = 3
const b = 4
println(a == a)
```

Compare it with what you meant:

```ts
const a = 3
const b = 4
println(a == b)
```
