# E0325: override with a different signature

An `override` method's parameters or return type differ from the method it overrides.
Callers that use the base type rely on the base signature, so an override must keep it.

```ppl
class A {
  public virtual count(): i32 { 1 }
}
class B extends A {
  public override count(): string { "two" }
}
```

Give the override the same parameter and return types as the base method.

```ppl
class A {
  public virtual count(): i32 { 1 }
}
class B extends A {
  public override count(): i32 { 2 }
}
```
