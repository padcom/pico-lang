# E0352: comptime code that uses a runtime variable

Comptime code runs before the program does, so it can't see the program's variables or a
function's parameters: they don't have values yet. It can only use constants and call
functions.

```ppl
function next(n: int): int { comptime n + 1 }
```

Compute the value at run time, or make the input a constant (or a `comptime` parameter).

```ppl
function next(n: int): int { n + 1 }
println(next(1))
```
