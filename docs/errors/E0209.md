# E0209: `break` with a value outside `loop`

A `break value` inside a `while`, `for` or `do … while` loop. Only `loop { … }` is an
expression: it runs until a `break` and evaluates to that break's value. The other loops can
end without any `break`, so they have no value to give.

```ppl
let i = 0
while (true) {
  i++
  break i
}
```

Use `loop` to produce a value, or a plain `break` and a variable.

```ppl
let i = 0
const result = loop {
  i++
  break i
}
println(result)
```
