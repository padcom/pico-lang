# W0027: a promise is dropped without `await` or `catch`

A promise that's dropped (not awaited, returned or stored) fails silently: nobody sees its error. A chain that ends with `.catch(…)` or `.then(onValue, onError)` handles it. The rule is off by default; turn it on with `"lint": { "floatingPromise": true }` in `project.json`.

```ts
async function save(): Promise<int> { 1 }

async function main(): Promise<void> {
  save()
  println("saved")
}
await main()
```

`await` it:

```ts
async function save(): Promise<int> { 1 }

async function main(): Promise<void> {
  await save()
  println("saved")
}
await main()
```
