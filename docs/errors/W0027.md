# W0027: a promise is dropped without `await` or `catch`

A promise that's dropped (not awaited, returned or stored) fails silently: nobody sees its error. A chain that ends with `.catch(…)` or `.then(onValue, onError)` handles it, and a promise that can't fail (`Promise<T, never>`, such as an `async` function's without `throws`) isn't reported. The rule is off by default; turn it on with `"lint": { "floatingPromise": true }` in `project.json`.

```ts
async function save(): Promise<int> throws Error { 1 }

async function main(): Promise<void> throws Error {
  save()
  println("saved")
}
await main()
```

`await` it:

```ts
async function save(): Promise<int> throws Error { 1 }

async function main(): Promise<void> throws Error {
  await save()
  println("saved")
}
await main()
```
