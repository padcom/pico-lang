# E0308: mismatched types

A value's type isn't the type its place expects: the annotation of a variable, a parameter,
a function's return type, a field. ppl converts implicitly only where nothing can be lost (a
smaller integer to a larger one, an integer to a wide enough float, `T` to `T?`); everything
else needs an explicit conversion.

```ts
const count: i32 = "five"
```

Give a value of the expected type, or convert it explicitly: `as` between numbers,
`parseInt`/`parseFloat` from strings, `toString()` (or a template) to a string.

```ts
const count: i32 = 5
const label: string = `${count}`
```
