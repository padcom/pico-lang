# W0064: a regex has an unnamed capture group

An unnamed capture group (`(…)`) is found by its position, which changes when groups are added. Name it (`(?<name>…)`) or, when you don't need its text, don't capture (`(?:…)`). The rule is off by default; turn it on with `"lint": { "preferNamedCaptureGroup": true }` in `project.json`.

```ts
const date = /(\d{4})-(\d{2})/
println(date.test("2026-11"))
```

Name the groups:

```ts
const date = /(?<year>\d{4})-(?<month>\d{2})/
println(date.test("2026-11"))
```
