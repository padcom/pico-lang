# E0305: invalid `as` conversion

`as` converts only between types where the conversion is well defined: numbers to numbers,
`char` to and from integers, and a few others. Anything else, such as `bool` to `char`, needs
an explicit expression that says what the result should be.

```ppl
const c = true as char
```

Write the conversion out, for example with `if`.

```ppl
const flag = true
const c: char = if (flag) "y" else "n"
```
