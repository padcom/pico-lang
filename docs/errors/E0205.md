# E0205: `break` or `continue` outside a loop

A `break` or `continue` that isn't inside a `for`, `while`, `do … while` or `loop` body. A
function or closure body starts fresh: a `break` inside a callback can't leave a loop around
the call.

```ppl
const n = 3
if (n > 2) {
  break
}
```

Use `return` to leave a function early, or move the statement into the loop it should end.

```ppl
for (const n of [1, 2, 3]) {
  if (n > 2) {
    break
  }
  println(n)
}
```
