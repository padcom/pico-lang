# E0340: import of a name the module doesn't export

The module exists but has no exported declaration with that name: it's misspelled, or it's
declared without `export` and so is private to its module.

```ppl
import { clmp } from "std/math"
println(clmp(5.0, 0.0, 1.0))
```

Import a name the module exports (the message suggests close spellings), or add `export` to
the declaration in your own module.

```ppl
import { clamp } from "std/math"
println(clamp(5.0, 0.0, 1.0))
```
