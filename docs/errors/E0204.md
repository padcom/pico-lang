# E0204: assignment to a `const` binding

An assignment (`=`, `+=`, `++`, …) to a name declared with `const`. A `const` binding is fixed
once it's initialized; that's what makes it safe to read anywhere without tracking changes.
(The object it refers to may still be mutable.)

```ts
const total = 0
total = 1
```

Declare the binding with `let` if it has to change.

```ts
let total = 0
total = 1
println(total)
```
