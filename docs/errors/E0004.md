# E0004: invalid numeric literal or suffix

A number literal that pico can't read: an unknown type suffix, a digit that doesn't belong to
its base (`0b2`, `0o9`) or a malformed exponent. Suffixes name the literal's type, so only the
numeric type names are allowed: `i8 i16 i32 i64 u8 u16 u32 u64 isize usize f32 f64`.

```ts
const size = 10q
println(size)
```

Use one of the valid suffixes, or none and let the type come from context.

```ts
const size = 10u32
println(size)
```
