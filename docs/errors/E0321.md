# E0321: method overrides a virtual method without `override`

A subclass declares a method with the same name as a `virtual` method of its base class but
without `override`. pico requires the keyword so that overriding is always intentional and
visible, never an accident of naming.

```ts
class Animal {
  public virtual speak(): string { "..." }
}
class Dog extends Animal {
  public speak(): string { "Woof" }
}
```

Add `override`, or rename the method if it isn't meant to replace the base one.

```ts
class Animal {
  public virtual speak(): string { "..." }
}
class Dog extends Animal {
  public override speak(): string { "Woof" }
}
```
