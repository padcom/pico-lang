# W0022: a block is empty

An empty block (outside a function body) is usually unfinished code. A block holding just a comment is fine, and says why it's empty. The rule is off by default; turn it on with `"lint": { "emptyBlock": true }` in `project.json`.

```ts
const n = 3
if (n > 5) {
} else {
  println("small")
}
```

Remove it, or say why it's empty:

```ts
const n = 3
if (n > 5) {
  // big numbers need nothing here
} else {
  println("small")
}
```
