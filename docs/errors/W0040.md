# W0040: an arrow function's block body holds a single expression

An arrow function whose block only returns a value can return it directly after `=>`. The rule is off by default; turn it on with `"lint": { "arrowBodyStyle": true }` in `project.json`.

```ts
const double = (n: i32) => { return n * 2 }
println(double(2))
```

Write the value after `=>`:

```ts
const double = (n: i32) => n * 2
println(double(2))
```
