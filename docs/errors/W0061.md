# W0061: a doc comment's tags don't match the declaration

The tags of a function's doc comment should match its declaration: a `@param` with a description for each parameter, in order (and no other); `@returns` with a description when it returns something (and not when it doesn't); `@yields` exactly on generators; no types or defaults in tags (the signature has them); known tags, with no text on tags that take none. A doc comment with `@inheritdoc` is exempt. The rule is off by default; turn it on with `"lint": { "docTags": true }` in `project.json`.

```ts
/**
 * Adds two numbers.
 *
 * @param a the first
 * @returns the sum
 */
function add(a: i32, b: i32): i32 { a + b }
println(add(1, 2))
```

Document every parameter:

```ts
/**
 * Adds two numbers.
 *
 * @param a the first
 * @param b the second
 * @returns the sum
 */
function add(a: i32, b: i32): i32 { a + b }
println(add(1, 2))
```
