# E0355: an `@export`ed or `extern` function whose signature can't cross to JavaScript or C

Functions called from C (`extern`) or JavaScript (`@export`) can only take and return types
that both sides lay out the same way: numbers, `bool`, pointers and `@pod` structs for C. A
ppl `string`, array or class is managed by ppl's runtime and can't cross directly.

```ppl
extern "C" {
  function getenv(name: string): string
}
```

Use the C types: return `ptr<u8>` and copy it into a ppl string with `string.fromC`.

```ppl
extern "C" {
  function getenv(name: string): ptr<u8>
}
```
