# W0019: `finally` exits with `return`, `throw`, `break` or `continue`

`return`, `throw`, `break` or `continue` in a `finally` block replaces the result or the error of the `try`: an error thrown in the `try` is lost. The rule is off by default; turn it on with `"lint": { "unsafeFinally": true }` in `project.json`.

```ts
function read(): i32 {
  try {
    return 1
  } finally {
    return 2
  }
}
println(read())
```

Leave `finally` for cleaning up:

```ts
function read(): i32 {
  try {
    return 1
  } finally {
    println("done")
  }
}
println(read())
```
