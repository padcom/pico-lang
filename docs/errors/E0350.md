# E0350: a comptime value that can't be part of the program (an object or a function)

A comptime result is written into the compiled program as a constant. Numbers, strings,
booleans, arrays and structs of those can be; class instances and functions can't, because
they belong to the compiler's evaluation, not to the program.

```ts
class Box { public v: int = 0 }
comptime const D = new Box()
```

Compute plain data at comptime and build the object at run time from it.

```ts
class Box { public v: int = 0 }
comptime const V = 6 * 7
const d = new Box()
d.v = V
println(d.v)
```
