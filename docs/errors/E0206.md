# E0206: cannot find a type

A type annotation that names a type that isn't declared or imported. It's usually a typo, a
name from another language (`Integer`, `int32`), or a type from another module that hasn't been
imported.

```ppl
function double(n: Integer): i64 { n * 2 }
println(double(2))
```

Use a built-in type (`i64`, `f64`, `string`, …), declare the type, or import it.

```ppl
function double(n: i64): i64 { n * 2 }
println(double(2))
```
