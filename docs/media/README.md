# PPL brand assets

Vectorized from the selected PPL logo designs. All SVG files contain real editable vector paths (not embedded PNGs), with transparent backgrounds.

- `ppl-logo.svg`: primary horizontal full-color logo
- `ppl-icon.svg`: square mark for VS Code extensions and avatars
- `ppl-logo-monochrome.svg`: single-color horizontal logo
- `ppl-icon-monochrome.svg`: single-color square icon
- `ppl-icon-white.svg`: white square icon for dark backgrounds
- PNG previews and 128/256/512px extension icons included.

For a VS Code extension, use `ppl-icon-128.png` or `ppl-icon-256.png` in the package's `icon` field. SVGs are true vectors derived from the raster designs, so very small details may differ slightly from the source.
