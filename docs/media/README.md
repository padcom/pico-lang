# Pico brand assets

Vectorized from the selected Pico logo designs. All SVG files contain real editable vector paths (not embedded PNGs), with transparent backgrounds.

- `pico-logo.svg`: primary horizontal full-color logo
- `pico-icon.svg`: square mark for VS Code extensions and avatars
- `pico-logo-monochrome.svg`: single-color horizontal logo
- `pico-icon-monochrome.svg`: single-color square icon
- `pico-icon-white.svg`: white square icon for dark backgrounds
- `pico-icon-file.svg`: file icon for `.pi` files (the VS Code extension uses it as `images/pico-file.svg`, plus a white-and-lilac `pico-file-dark.svg` for dark themes)
- PNG previews and 128/256/512px extension icons included.

For a VS Code extension, use `pico-icon-128.png` or `pico-icon-256.png` in the package's `icon` field. SVGs are true vectors derived from the raster designs, so very small details may differ slightly from the source.
