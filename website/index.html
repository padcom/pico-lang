Pico

The syntax you know.
Native speed.

Pico is a statically typed, garbage-collected language with TypeScript-based syntax. It compiles ahead of time through LLVM to native code on Linux, macOS and Windows, and to WebAssembly for the browser and WASI.

Take the tour View on GitHub
hello.pi
import { readText } from "std/fs"

const text = await readText("notes.txt")
let count = 0
for (const line of text.split("\n")) {
  if (line.startsWith("#")) count++
}
println(`${count} headings`)
$ pico run hello.pi
12 headings

The basics

Familiar where it can be, stricter where it matters.

TypeScript look and feel

Classes, interfaces, generics, arrow functions, template literals and async/await, written the way you already write them.

Sound, nominal types

No any, no undefined, and a single null that has to be declared. Types are compared by name, not by shape.

Built for speed

Sized numbers (i8 to u64, f32, f64), struct value types, monomorphized generics and an LLVM backend.

Everything is an expression

if, match, blocks and loops produce values. A function's last expression is its result.

Native and the web

One codebase for x86_64 and arm64 executables, WASI modules and the browser, with C and JavaScript interop.

One tool

pico builds, runs, tests, formats and lints, manages packages, and runs the REPL, the debugger and the language server.

A tour in ten features

Scroll down: the code on the right follows along.

    01

    Variables

    let declares a binding you can reassign. Types are inferred, or written after a colon. Nullable types are opt-in with ?, and the compiler narrows them after a check.

    let count = 0                    // inferred: int (i64)
let ratio: f32 = 0.5
let name: string = "Ann"

count += 1
name = `${name} Smith`

let nick: string? = null         // string? is string | null
println(nick?.length ?? 0)       // 0

if (nick != null) {
  println(nick.toUpperCase())    // narrowed to string
}
    02

    Constants

    const bindings can't be reassigned. Constant expressions are folded by the compiler, and overflow is caught at compile time. For deep read-only access, use readonly fields and immutable views.

    const MAX_USERS = 1_000
const KB = 1 << 10                 // folded at compile time
const BAD = 255u8 + 1u8          // error: overflow in a constant

const list = [1, 2]
list = []                        // error: const binding
list.push(3)                     // ok: the binding is const, not the list

function render(scene: immutable Scene) {
  println(scene.count())         // ok: a readonly method
  scene.nodes.push(node)         // error: mutation through immutable
}
    03

    Lists

    Arrays grow, are bounds-checked and come with the methods you expect. Destructuring and for…of work as usual. Fixed-size arrays and tuples are value types stored inline.

    const xs: i32[] = [5, 3, 8]
xs.push(1)
xs.sort()
println(xs)                                   // [1, 3, 5, 8]
println(xs.map(n => n * 2).filter(n => n > 4)) // [6, 10, 16]

const [head, ...tail] = xs
for (const [i, x] of xs.enumerate()) println(`${i}: ${x}`)

const grid: [u8; 16] = [0; 16]     // fixed-size, inline
const pair: [string, i32] = ["age", 42]   // tuple
xs[10]                             // panic: index out of bounds
    04

    Maps

    Map and Set are generic built-ins. An object literal typed as a Map becomes a map literal, and iterating gives you key/value tuples.

    const ages = new Map<string, i32>()
ages.set("Ann", 31)
ages.set("Bob", 27)

const env: Map<string, string> = {   // a map literal
  "LANG": "C",
  HOME: "/home/ann",
}

for (const [name, age] of ages) println(`${name}: ${age}`)
for (const key of env.keys()) println(key)

const tags = new Set<string>(["new", "sale"])
    05

    Classes

    Parameter properties, getters, setters and overloaded constructors. Methods are final unless they're marked virtual, and overriding requires override. Inside a class, this. is optional.

    class Animal {
  constructor(public name: string, protected age: i32) {}

  public get description(): string { `${name} (${age})` }
  public virtual speak(): string { "..." }
  public describe(): string { `${name} says ${speak()}` }
}

class Dog extends Animal {
  constructor(name: string) { super(name, 3) }
  public override speak(): string { "Woof" }
}

const d: Animal = new Dog("Rex")
println(d.describe())            // Rex says Woof
println(d.description)           // Rex (3)
    06

    Interfaces

    Interfaces are nominal: a class implements one only when it says so. They can carry default methods, extend each other, and be implemented by structs and enums too.

    interface Shape {
  area(): f64
  describe(): string { `area ${area():.2f}` }   // default method
}

class Circle implements Shape {
  constructor(public r: f64) {}
  public area(): f64 { Math.PI * r * r }
}

class Blob {                     // the same shape, but no `implements`
  public area(): f64 { 1 }
}

const c: Shape = new Circle(2)
println(c.describe())            // area 12.57
const b: Shape = new Blob()      // error: interfaces are nominal
    07

    Lambdas

    Arrow functions are first-class values with typed signatures. They capture let bindings by reference, const bindings by value, and this lexically.

    type Predicate<T> = (x: T) => bool

function keep<T>(xs: T[], test: Predicate<T>): T[] { xs.filter(test) }

const evens = keep([1, 2, 3, 4], n => n % 2 == 0)   // [2, 4]

function makeCounter(): () => int {
  let n = 0
  () => ++n                      // the last expression is the result
}

const next = makeCounter()
next(); next()
println(next())                  // 3

const sum = [1, 2, 3].reduce((a, b) => a + b, 0)
    08

    The match operator

    match is an expression. It destructures enums, structs, arrays and tuples, and supports guards, or-patterns, ranges and type tests. A match that misses a case is a compile error.

    enum Shape {
  Circle(r: f64),
  Rect(w: f64, h: f64),
  Empty,
}

const desc = match (shape) {
  Circle { r } if r > 10 => "big circle",
  Circle { r }           => `circle ${r}`,
  Rect(w, h) if w == h   => "square",
  Rect { w, h }          => `rect ${w}x${h}`,
  Empty                  => "nothing",
}

const kind = match (status) {
  200 | 201 | 204 => "ok",
  300..400        => "redirect",
  _               => "other",
}
    09

    Comptime

    Ordinary Pico code can run inside the compiler. Use it to build lookup tables, read files at build time, take compile-time parameters, or pick an implementation per target.

    function buildCrcTable(): [u32; 256] {
  const t: [u32; 256] = [0; 256]
  for (const i of 0..256) {
    let c = i as u32
    for (const _ of 0..8) c = if ((c & 1) != 0) 0xEDB88320 ^ (c >>> 1) else c >>> 1
    t[i] = c
  }
  t
}
comptime const CRC_TABLE = buildCrcTable()   // runs in the compiler

function zeros<comptime N: i32>(): [f32; N] { [0; N] }
const v = zeros<4>()

const VERSION = comptime comptime.readFile("VERSION").trim()
const impl = comptime if (target.arch == "wasm32") wasmImpl else nativeImpl
    10

    Decorators

    Decorators are comptime functions that inspect and rewrite declarations. They can add members, wrap bodies with type-checked templates, and report errors. The standard library brings @derive.

    import { FunctionDecl } from "std/meta"

export decorator function memoize(fn: FunctionDecl): FunctionDecl {
  const cache = fn.addStatic("cache",
    `new Map<u64, ${fn.returnType}>()`)          // a hidden static
  fn.wrapBody((args, call) => `
    const key = ${args.hashKey()}
    const hit = ${cache}.get(key)
    if (hit != null) return hit
    const v = ${call}
    ${cache}.set(key, v)
    v
  `)
  fn
}

@memoize
function fib(n: i64): i64 { if (n < 2) n else fib(n - 1) + fib(n - 2) }

@derive(Eq, Hash)
class User { constructor(public id: i64, public name: string) {} }
    example.pi

    One tool for the whole workflow

    No separate build system, formatter, test runner or package manager to set up.

    pico run script.pi            # compile and run
pico build --release          # native executable
pico build --target wasm32-wasi
pico test --watch             # every *.test.pi
pico fmt --check
pico lint
pico doc
pico explain E0308            # long-form error help
    • Language server for diagnostics, formatting and navigation in VS Code.
    • Debugger through pico dap and lldb.
    • Packages come straight from git, pinned by project.json.
    • Targets: Linux, macOS and Windows on x86_64 and arm64, WASI and the browser.
